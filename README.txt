DLSC WEBSITE DESIGN OPTIONS — GITHUB PAGES

1. Unzip DLSC-GitHub-Pages.zip on your Mac.
2. Open the extracted DLSC-GitHub-Pages folder.
3. On the empty GitHub repository page choose uploading an existing file.
4. Drag index.html, all three option HTML files, and the entire assets folder into the GitHub upload area. Drag the CONTENTS of this folder, not the outer DLSC-GitHub-Pages folder. README.txt is optional.
5. Wait for uploads and commit changes.
6. Settings > Pages > Deploy from a branch > main > / (root) > Save.
7. Open the website address that GitHub displays when deployment completes.

Keep assets and the HTML files together. The HTML files now load images from the assets folder. Each option still contains all eleven public pages and the build guide.

This package replaces the large embedded-image files for online hosting. Your earlier single-file versions remain useful for viewing offline.
